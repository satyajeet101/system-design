## Basics
- **Virtualization:** AWS uses virtualization to create virtual machines (EC2 instances) that run on physical servers. This allows for flexible resource allocation and isolation between different users' workloads.
- **Public vs. Private Cloud:** AWS is a public cloud provider, meaning that its services are available to anyone over the internet. In contrast, a private cloud is a cloud environment that is dedicated to a single organization and is not shared with others.
- **Regions and Availability Zones:** AWS is organized into regions, which are geographic areas that contain multiple availability zones (AZs). AZs are isolated data centers within a region that provide redundancy and high availability for applications.
